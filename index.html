LEARNING PATH

从概念理解
到模型工程

课程主体按三个阶段组织：先建立语言处理的共同基础，再观察模型内部过程，最后进入工程化的模型行为实验；随后可进入拓展探索与决策智能。

  1. 01

    UNDERSTAND

    入门夯实

    建立概念、预处理与评测基础。

  2. 02

    SIMULATE

    原理仿真

    观察模型内部计算过程。

  3. 03

    ENGINEER

    工程虚仿

    理解 Transformer 与生成模型行为。

  4. 04

    EXPLORE · OPTIONAL EXTENSION

    拓展探索

    探索 Tokenizer、Retrieval 与 Decoding 等现代 NLP 工程机制。

  5. 05

    DECIDE

    决策智能

    从生成结果走向结构化判断。

ABOUT THE PROJECT

关于 NLP 百宝箱

这是一个基于 HTML、CSS 与 JavaScript 构建的自然语言处理交互式学习平台。它将通过可视化和实验，帮助学习者理解 NLP 基础概念、深度学习模型，以及 Transformer / LLM 的关键机制。
